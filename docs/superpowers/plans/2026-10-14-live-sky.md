# Live Sky Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Show the other people flying the site right now as faint ghost ships wearing their plume colour, with their country on scan, relayed by a Durable Object room in `beacon-api`.

**Architecture:** A shared, pure protocol module (`src/utils/liveSkyProtocol.ts`) validates messages on both sides. The server is a pure room model (`beacon-api/src/sky.ts`), a pure upgrade gate (`beacon-api/src/liveRoute.ts`) and a thin hibernatable-WebSocket Durable Object adapter (`Sky` in `beacon-api/src/index.ts`). The client is a pure model (`src/utils/liveSky.ts`: parsing, interpolation, send rule), a socket lifecycle class (`src/utils/liveSkyConnection.ts`), and one canvas component (`src/components/canvas/Ghosts.tsx`) that drives the connection per frame and draws up to 8 pooled ghost slots.

**Tech Stack:** TypeScript 6, React 19, @react-three/fiber 9, three 0.185, zustand 5, Vitest 4, Puppeteer e2e harness, Cloudflare Workers + Durable Objects (WebSocket Hibernation API), Wrangler via `npx`.

**Spec:** `docs/superpowers/specs/2026-10-14-live-sky-design.md` (read it before starting; this plan argues from it).

## Review Focus

These are inputs the spec implies that no headline test would catch; each has a test in the owning task.

1. **The server echoes my own ship in a snapshot.** I must never see my own ghost. The client drops any ship whose id matches the id from `hello` (Task 5, test "never shows its own ship").
2. **Toggle off then on while a reconnect is pending.** The visitor expects ghosts back at once, not after the backoff. Turning live sky back on cancels the pending retry and connects immediately (Task 5, test "re-enabling during a pending retry connects at once").
3. **A socket is closed twice** (the room closes a flooder, then the runtime fires `webSocketClose`). Leaving must be idempotent, with no second `peers` broadcast (Task 2, test "leaving twice is a no-op").
4. **A pilot sitting still changes plume colour.** Others should see the new colour. A plume change counts as a change worth sending (Task 4, test "a plume change while still is sent").
5. **A pilot leaves, or the visitor turns live sky off, while a ghost is the scan target.** A later scan must never report a pilot who is gone. Ghost scannables and the ghost registry are removed whenever a slot empties, when the feature is toggled off, and on unmount (Task 7 code; Task 8 e2e check "turning it off removes the ghost scan target").

```ts
import { COSMIC_BOUNDS } from "../constants";
import { hasPlumeColour } from "../data/plumeColors";

/**
 * Live sky wire protocol (docs/superpowers/specs/2026-10-14-live-sky-design.md §3).
 * Shared by the client and beacon-api's Sky room, so both validate the same way,
 * as src/utils/beacons.ts is for beacons.
 */

export type Vec3 = [number, number, number];
export type Quat = [number, number, number, number];
export interface ShipState { p: Vec3; q: Quat; plume: string }
export interface SnapShip extends ShipState { id: string; cc: string | null }

export type ServerMessage =
  | { t: "hello"; id: string; peers: number }
  | { t: "peers"; n: number }
  | { t: "sync" }
  | { t: "snap"; ships: SnapShip[] }
  | { t: "full" };

/** Open sockets per room; the next one is turned away with `full`. */
export const SKY_CAP = 40;
export const MAX_MESSAGE_BYTES = 256;
/** Room-wide gap between snapshots. */
export const SNAP_INTERVAL_MS = 250;
/** More messages than this in one second closes the socket. A good client sends 5. */
export const FLOOD_PER_SECOND = 10;
/** A ship mid-wrap can sit a hair past ±COSMIC_BOUNDS. */
const EDGE_SLACK = 1;

const finite = (v: unknown): v is number => typeof v === "number" && Number.isFinite(v);

/** q scaled to unit length, or null unless it is close to unit already (|q|² in 0.9–1.1). */
export function normQuat(q: unknown): Quat | null {
  if (!Array.isArray(q) || q.length !== 4 || !q.every(finite)) return null;
  const [x, y, z, w] = q as Quat;
  const len2 = x * x + y * y + z * z + w * w;
  if (len2 < 0.9 || len2 > 1.1) return null;
  const l = Math.sqrt(len2);
  return [x / l, y / l, z / l, w / l];
}

function inWorld(p: unknown): p is Vec3 {
  return Array.isArray(p) && p.length === 3 && p.every((v) => finite(v) && Math.abs(v) <= COSMIC_BOUNDS + EDGE_SLACK);
}

/** A client's `me` message, as the room sees it. Null for anything invalid. */
export function parseMe(raw: unknown): ShipState | null {
  if (typeof raw !== "string" || new TextEncoder().encode(raw).length > MAX_MESSAGE_BYTES) return null;
  let m: unknown;
  try { m = JSON.parse(raw); } catch { return null; }
  if (!m || typeof m !== "object" || Array.isArray(m)) return null;
  const { t, p, q, plume } = m as Record<string, unknown>;
  if (t !== "me" || !inWorld(p) || typeof plume !== "string" || !hasPlumeColour(plume)) return null;
  const nq = normQuat(q);
  return nq ? { p: [p[0], p[1], p[2]], q: nq, plume } : null;
}

/** Rounded for the wire: positions to 0.01, quaternion components to 0.001. */
export function roundState(s: ShipState): ShipState {
  return {
    p: s.p.map((v) => Math.round(v * 100) / 100) as Vec3,
    q: s.q.map((v) => Math.round(v * 1000) / 1000) as Quat,
    plume: s.plume,
  };
}

/** CF-IPCountry as a public code: unknown (XX), Tor (T1) and anything malformed become null. */
export function publicCountry(cc: string | null | undefined): string | null {
  return cc && /^[A-Z]{2}$/.test(cc) && cc !== "XX" && cc !== "T1" ? cc : null;
}
```

```ts
import {
  parseMe, roundState, SKY_CAP, SNAP_INTERVAL_MS, FLOOD_PER_SECOND,
  type ServerMessage, type ShipState, type SnapShip,
} from "../../src/utils/liveSkyProtocol";

/**
 * The live sky room, free of Cloudflare bindings so it can be unit tested
 * (tests/skyRoom.test.ts). index.ts's Sky Durable Object wires it to
 * hibernatable WebSockets. Spec: docs/superpowers/specs/2026-10-14-live-sky-design.md §2.
 *
 * Nothing here is stored. A pilot is a random id, a public country code, and
 * their last pose, kept in the socket's attachment; closing the socket forgets them.
 */

export interface Pilot {
  id: string;
  cc: string | null;
  last: ShipState | null;
  /** Flood window: messages counted since `start`. */
  win: { start: number; count: number };
}
export interface Room { pilots: Pilot[]; lastSnapAt: number; trailingDue: boolean }
export interface Outgoing { to: string; msg: ServerMessage }

export const newRoom = (): Room => ({ pilots: [], lastSnapAt: -Infinity, trailingDue: false });

/** 8 random base-36 characters. Never derived from anything about the visitor. */
export function randomPilotId(): string {
  const bytes = crypto.getRandomValues(new Uint8Array(8));
  return [...bytes].map((b) => (b % 36).toString(36)).join("");
}

export function buildSnap(room: Room, forId: string): ServerMessage {
  const ships: SnapShip[] = [];
  for (const p of room.pilots) if (p.id !== forId && p.last) ships.push({ id: p.id, cc: p.cc, ...p.last });
  return { t: "snap", ships };
}

const snapAll = (room: Room): Outgoing[] => room.pilots.map((p) => ({ to: p.id, msg: buildSnap(room, p.id) }));

export function onJoin(room: Room, id: string, cc: string | null, now: number):
  { ok: false; out: ServerMessage } | { ok: true; pilot: Pilot; out: Outgoing[] } {
  if (room.pilots.length >= SKY_CAP) return { ok: false, out: { t: "full" } };
  const pilot: Pilot = { id, cc, last: null, win: { start: now, count: 0 } };
  room.pilots.push(pilot);
  const n = room.pilots.length - 1;
  const out: Outgoing[] = [{ to: id, msg: { t: "hello", id, peers: n } }];
  // Everyone already here, straight away: a still pilot sends nothing.
  if (n > 0) out.push({ to: id, msg: buildSnap(room, id) });
  for (const p of room.pilots) {
    if (p.id === id) continue;
    out.push({ to: p.id, msg: { t: "peers", n } });
    out.push({ to: p.id, msg: { t: "sync" } });
  }
  return { ok: true, pilot, out };
}

export function onMessage(room: Room, pilot: Pilot, raw: unknown, now: number):
  { out: Outgoing[]; close: boolean; trailingIn: number | null } {
  if (now - pilot.win.start >= 1000) pilot.win = { start: now, count: 0 };
  pilot.win.count++;
  if (pilot.win.count > FLOOD_PER_SECOND) return { out: [], close: true, trailingIn: null };
  const state = parseMe(raw);
  if (!state) return { out: [], close: false, trailingIn: null };
  pilot.last = roundState(state);
  const wait = room.lastSnapAt + SNAP_INTERVAL_MS - now;
  if (wait <= 0) {
    room.lastSnapAt = now;
    room.trailingDue = false;
    return { out: snapAll(room), close: false, trailingIn: null };
  }
  // Inside the window: one trailing snapshot carries this (and any later) move.
  if (room.trailingDue) return { out: [], close: false, trailingIn: null };
  room.trailingDue = true;
  return { out: [], close: false, trailingIn: wait };
}

/** The trailing snapshot a throttled message scheduled; empty if something already sent one. */
export function onTrailing(room: Room, now: number): Outgoing[] {
  if (!room.trailingDue) return [];
  room.trailingDue = false;
  room.lastSnapAt = now;
  return snapAll(room);
}

export function onLeave(room: Room, id: string, now: number): Outgoing[] {
  const i = room.pilots.findIndex((p) => p.id === id);
  if (i < 0) return [];
  room.pilots.splice(i, 1);
  room.lastSnapAt = now;
  room.trailingDue = false;
  const n = room.pilots.length - 1;
  return [
    ...room.pilots.map((p) => ({ to: p.id, msg: { t: "peers", n } as ServerMessage })),
    ...snapAll(room),
  ];
}
```

```ts
import { rateKey, type RequestLimiter } from "./handler";

export interface LiveDeps {
  allowedOrigins: readonly string[];
  /** Same per-pilot budget as beacons (env.LIMITER); optional so tests need no binding. */
  limiter?: RequestLimiter;
}

/**
 * Gates GET /live before it reaches the Sky room. Returns the refusal, or null
 * to forward the upgrade. As with beacon drops, the Origin check only stops
 * other sites' pages from joining; the request budget is what bounds abuse.
 */
export async function refuseLive(req: Request, deps: LiveDeps): Promise<Response | null> {
  if (req.method !== "GET" || req.headers.get("Upgrade")?.toLowerCase() !== "websocket") {
    return new Response("expected a websocket upgrade", { status: 426 });
  }
  const origin = req.headers.get("Origin");
  if (!origin || !deps.allowedOrigins.includes(origin)) return new Response("origin", { status: 403 });
  const ip = req.headers.get("CF-Connecting-IP") ?? "unknown";
  if (deps.limiter && !(await deps.limiter.limit({ key: rateKey(ip) })).success) {
    return new Response("slow down", { status: 429, headers: { "Retry-After": "60" } });
  }
  return null;
}
```

```ts
/**
 * The live sky room: one Durable Object of hibernatable WebSockets. With
 * nobody moving it gets no events and hibernates, so an empty or solo sky
 * costs nothing. The room logic lives in sky.ts; this is the adapter.
 */
export class Sky {
  private ctx: DurableObjectState;
  private room = newRoom();
  private sockets = new Map<string, HibernatableSocket>();
  private trailing: ReturnType<typeof setTimeout> | null = null;

  constructor(ctx: DurableObjectState, _env: unknown) {
    this.ctx = ctx;
    // Waking from hibernation: the sockets' attachments are the whole room.
    for (const ws of ctx.getWebSockets()) {
      const p = ws.deserializeAttachment() as Pilot | null;
      if (p) { this.room.pilots.push(p); this.sockets.set(p.id, ws); }
    }
  }

  async fetch(req: Request): Promise<Response> {
    const pair = new WebSocketPair();
    const client = pair[0], server = pair[1];
    this.ctx.acceptWebSocket(server);
    const joined = onJoin(this.room, randomPilotId(), publicCountry(req.headers.get("CF-IPCountry")), Date.now());
    if (!joined.ok) {
      // No attachment: webSocketClose ignores this socket.
      server.send(JSON.stringify(joined.out));
      server.close(1013, "full");
    } else {
      server.serializeAttachment(joined.pilot);
      this.sockets.set(joined.pilot.id, server);
      this.deliver(joined.out);
    }
    return new Response(null, { status: 101, webSocket: client } as ResponseInit);
  }

  webSocketMessage(ws: HibernatableSocket, message: string | ArrayBuffer): void {
    const id = (ws.deserializeAttachment() as Pilot | null)?.id;
    const pilot = this.room.pilots.find((p) => p.id === id);
    if (!pilot) return;
    const r = onMessage(this.room, pilot, message, Date.now());
    ws.serializeAttachment(pilot);
    if (r.close) {
      ws.close(1008, "too many messages");
      this.leave(ws);
      return;
    }
    this.deliver(r.out);
    if (r.trailingIn !== null && !this.trailing) {
      this.trailing = setTimeout(() => {
        this.trailing = null;
        this.deliver(onTrailing(this.room, Date.now()));
      }, r.trailingIn);
    }
  }

  webSocketClose(ws: HibernatableSocket): void { this.leave(ws); }
  webSocketError(ws: HibernatableSocket): void { this.leave(ws); }

  private leave(ws: HibernatableSocket) {
    const id = (ws.deserializeAttachment() as Pilot | null)?.id;
    if (!id) return;
    this.sockets.delete(id);
    this.deliver(onLeave(this.room, id, Date.now()));
  }

  private deliver(out: readonly Outgoing[]) {
    for (const o of out) {
      try { this.sockets.get(o.to)?.send(JSON.stringify(o.msg)); } catch { /* closing socket */ }
    }
  }
}
```

```markdown
The same Worker relays live sky: other visitors flying right now appear as
```

```ts
const isCount = (v: unknown): v is number => Number.isInteger(v) && (v as number) >= 0 && (v as number) <= SKY_CAP;
const clamp = (v: number) => Math.max(-COSMIC_BOUNDS, Math.min(COSMIC_BOUNDS, v));

function parseShip(row: unknown): SnapShip | null {
  if (!row || typeof row !== "object") return null;
  const { id, p, q, plume, cc } = row as Record<string, unknown>;
  if (typeof id !== "string" || id.length === 0 || id.length > 16) return null;
  if (!Array.isArray(p) || p.length !== 3 || !p.every((v) => typeof v === "number" && Number.isFinite(v))) return null;
  const nq = normQuat(q);
  if (!nq) return null;
  return {
    id,
    p: [clamp(p[0]), clamp(p[1]), clamp(p[2])],
    q: nq,
    plume: typeof plume === "string" && hasPlumeColour(plume) ? plume : "stock",
    cc: typeof cc === "string" ? publicCountry(cc) : null,
  };
}

/** A room message. Snapshots are untrusted: rows are clamped, cleaned or dropped, never trusted. */
export function parseServerMessage(raw: unknown): ServerMessage | null {
  if (typeof raw !== "string") return null;
  let m: unknown;
  try { m = JSON.parse(raw); } catch { return null; }
  if (!m || typeof m !== "object") return null;
  const o = m as Record<string, unknown>;
  switch (o.t) {
    case "hello": return typeof o.id === "string" && isCount(o.peers) ? { t: "hello", id: o.id, peers: o.peers } : null;
    case "peers": return isCount(o.n) ? { t: "peers", n: o.n } : null;
    case "sync": return { t: "sync" };
    case "full": return { t: "full" };
    case "snap":
      if (!Array.isArray(o.ships)) return null;
      return { t: "snap", ships: o.ships.slice(0, SKY_CAP).map(parseShip).filter((s): s is SnapShip => s !== null) };
    default: return null;
  }
}

export interface GhostPose { id: string; p: Vec3; q: Quat; plume: string; cc: string | null; alpha: number }
interface Sample { at: number; p: Vec3; q: Quat }
interface Track { samples: Sample[]; firstSeen: number; plume: string; cc: string | null }

const wrap = (v: number) => {
  const span = COSMIC_BOUNDS * 2;
  return ((((v + COSMIC_BOUNDS) % span) + span) % span) - COSMIC_BOUNDS;
};

function blend(a: Sample, b: Sample, k: number): { p: Vec3; q: Quat } {
  const p = [0, 1, 2].map((i) => wrap(a.p[i] + wrapDelta(a.p[i], b.p[i], COSMIC_BOUNDS) * k)) as Vec3;
  // Normalised lerp on the short arc; at 250 ms steps it is indistinguishable from slerp.
  const sign = a.q[0] * b.q[0] + a.q[1] * b.q[1] + a.q[2] * b.q[2] + a.q[3] * b.q[3] < 0 ? -1 : 1;
  const q = [0, 1, 2, 3].map((i) => a.q[i] * (1 - k) + b.q[i] * sign * k) as Quat;
  const l = Math.hypot(q[0], q[1], q[2], q[3]);
  return { p, q: [q[0] / l, q[1] / l, q[2] / l, q[3] / l] };
}

/** Recent snapshots per ghost, sampled RENDER_DELAY_MS in the past so motion is smooth. */
export class GhostBuffer {
  private tracks = new Map<string, Track>();

  get size(): number { return this.tracks.size; }

  /** One snapshot, stamped with its arrival time. A ghost missing from it has left. */
  push(ships: readonly SnapShip[], at: number): void {
    const seen = new Set<string>();
    for (const s of ships) {
      seen.add(s.id);
      const sample: Sample = { at, p: s.p, q: s.q };
      const t = this.tracks.get(s.id);
      if (!t) { this.tracks.set(s.id, { samples: [sample], firstSeen: at, plume: s.plume, cc: s.cc }); continue; }
      t.samples.push(sample);
      if (t.samples.length > 4) t.samples.shift();
      t.plume = s.plume;
      t.cc = s.cc;
    }
    for (const id of [...this.tracks.keys()]) if (!seen.has(id)) this.tracks.delete(id);
  }

  clear(): void { this.tracks.clear(); }

  sample(now: number, fadeMs = FADE_IN_MS): GhostPose[] {
    const t = now - RENDER_DELAY_MS;
    const out: GhostPose[] = [];
    for (const [id, tr] of this.tracks) {
      const s = tr.samples;
      let i = s.length - 1;
      while (i > 0 && s[i].at > t) i--;
      const a = s[i], b = s[i + 1];
      const pose = !b || t <= a.at
        ? { p: a.p, q: a.q }
        : blend(a, b, Math.min(1, (t - a.at) / Math.max(1, b.at - a.at)));
      const alpha = fadeMs <= 0 ? 1 : Math.min(1, (now - tr.firstSeen) / fadeMs);
      out.push({ id, p: pose.p, q: pose.q, plume: tr.plume, cc: tr.cc, alpha });
    }
    return out;
  }
}

/** The n ghosts nearest the ship, measured across the wrap. */
export function nearestGhosts(ship: { x: number; y: number; z: number }, ghosts: GhostPose[], n: number): GhostPose[] {
  const d = (g: GhostPose) => toroidalDistance3(ship.x, ship.z, ship.y, g.p[0], g.p[2], g.p[1], COSMIC_BOUNDS);
  return ghosts.map((g) => ({ g, d: d(g) })).sort((a, b) => a.d - b.d).slice(0, n).map((e) => e.g);
}

export interface SendState { lastAt: number; lastP: Vec3 | null; lastQ: Quat | null; lastPlume: string | null; syncPending: boolean }
export const newSendState = (): SendState => ({ lastAt: -Infinity, lastP: null, lastQ: null, lastPlume: null, syncPending: false });

/** Spec §3.2: only with company, at most every 200 ms, and only when something changed or the room asked. */
export function shouldSend(s: SendState, peers: number, now: number, me: ShipState): boolean {
  if (peers <= 0 || now - s.lastAt < SEND_INTERVAL_MS) return false;
  if (s.syncPending || !s.lastP || !s.lastQ || s.lastPlume !== me.plume) return true;
  const moved = Math.hypot(
    wrapDelta(s.lastP[0], me.p[0], COSMIC_BOUNDS),
    wrapDelta(s.lastP[1], me.p[1], COSMIC_BOUNDS),
    wrapDelta(s.lastP[2], me.p[2], COSMIC_BOUNDS),
  ) > MOVE_EPS;
  const dot = Math.abs(s.lastQ[0] * me.q[0] + s.lastQ[1] * me.q[1] + s.lastQ[2] * me.q[2] + s.lastQ[3] * me.q[3]);
  const turned = 2 * Math.acos(Math.min(1, dot)) > TURN_EPS;
  return moved || turned;
}

export function markSent(s: SendState, now: number, me: ShipState): void {
  s.lastAt = now;
  s.lastP = [...me.p];
  s.lastQ = [...me.q];
  s.lastPlume = me.plume;
  s.syncPending = false;
}
```

```ts
import { GhostBuffer, markSent, newSendState, parseServerMessage, shouldSend } from "./liveSky";
import { roundState, type ShipState } from "./liveSkyProtocol";

/**
 * The live sky socket's lifecycle (spec §4.2): connect when wanted, back off on
 * failure, let go of a long-hidden tab, and stop for good on `full`. A plain
 * class read per frame through a ref, never React state.
 */

export interface SocketLike {
  readonly readyState: number;
  onopen: (() => void) | null;
  onmessage: ((e: { data: unknown }) => void) | null;
  onclose: (() => void) | null;
  onerror: (() => void) | null;
  send(data: string): void;
  close(code?: number): void;
}

export interface ConnectionDeps {
  url: string;
  createSocket(url: string): SocketLike;
  now(): number;
  setTimer(fn: () => void, ms: number): unknown;
  clearTimer(handle: unknown): void;
  random(): number;
}

const OPEN = 1;
export const HIDDEN_GRACE_MS = 60_000;
/** A connection that lasted this long resets the backoff. */
export const STABLE_MS = 30_000;

/** 2 s doubling to 60 s, ±25% jitter so a room restart doesn't get every client back at once. */
export function backoffMs(attempt: number, random: number): number {
  return Math.min(60_000, 2000 * 2 ** attempt * (0.75 + random * 0.5));
}

export class LiveSkyConnection {
  readonly ghosts = new GhostBuffer();
  peers = 0;
  /** The room was full: no retries until the next page load. */
  full = false;
  /** Pose messages sent (tests and the e2e probe read it). */
  sent = 0;

  private deps: ConnectionDeps;
  private socket: SocketLike | null = null;
  private selfId: string | null = null;
  private wanted = false;
  private hiddenLong = false;
  private attempt = 0;
  private openedAt = 0;
  private retryTimer: unknown = null;
  private hiddenTimer: unknown = null;
  private sendState = newSendState();

  constructor(deps: ConnectionDeps) { this.deps = deps; }

  get connected(): boolean { return this.socket?.readyState === OPEN; }

  setWanted(want: boolean): void {
    if (want === this.wanted) return;
    this.wanted = want;
    if (!want) this.cancelRetry();
    this.reconcile();
  }

  setVisible(visible: boolean): void {
    if (!visible) {
      if (this.hiddenTimer === null && !this.hiddenLong) {
        this.hiddenTimer = this.deps.setTimer(() => {
          this.hiddenTimer = null;
          this.hiddenLong = true;
          this.reconcile();
        }, HIDDEN_GRACE_MS);
      }
      return;
    }
    if (this.hiddenTimer !== null) { this.deps.clearTimer(this.hiddenTimer); this.hiddenTimer = null; }
    if (this.hiddenLong) { this.hiddenLong = false; this.reconcile(); }
  }

  /** Per frame. `me` is null while the ship may not be shared yet (the notice has not been shown). */
  tick(me: ShipState | null): void {
    const ws = this.socket;
    if (!me || !ws || ws.readyState !== OPEN) return;
    const r = roundState(me);
    const now = this.deps.now();
    if (!shouldSend(this.sendState, this.peers, now, r)) return;
    try {
      ws.send(JSON.stringify({ t: "me", p: r.p, q: r.q, plume: r.plume }));
      this.sent++;
      markSent(this.sendState, now, r);
    } catch { /* closing; onclose follows */ }
  }

  dispose(): void {
    this.wanted = false;
    this.cancelRetry();
    if (this.hiddenTimer !== null) { this.deps.clearTimer(this.hiddenTimer); this.hiddenTimer = null; }
    this.drop();
  }

  private get shouldBeOpen(): boolean { return this.wanted && !this.hiddenLong && !this.full; }

  private reconcile(): void {
    if (!this.shouldBeOpen) { this.cancelRetry(); this.drop(); return; }
    if (!this.socket && this.retryTimer === null) this.open();
  }

  private open(): void {
    let ws: SocketLike;
    try { ws = this.deps.createSocket(this.deps.url); } catch { this.scheduleRetry(); return; }
    this.socket = ws;
    ws.onopen = () => { this.openedAt = this.deps.now(); };
    ws.onmessage = (e) => this.receive(e.data);
    ws.onclose = () => this.closed(ws);
    ws.onerror = () => { /* onclose follows */ };
  }

  private closed(ws: SocketLike): void {
    if (this.socket !== ws) return; // one we let go of on purpose
    this.socket = null;
    const lasted = this.openedAt ? this.deps.now() - this.openedAt : 0;
    this.reset();
    if (lasted >= STABLE_MS) this.attempt = 0;
    if (this.shouldBeOpen) this.scheduleRetry();
  }

  private scheduleRetry(): void {
    const ms = backoffMs(this.attempt++, this.deps.random());
    this.retryTimer = this.deps.setTimer(() => { this.retryTimer = null; this.reconcile(); }, ms);
  }

  private cancelRetry(): void {
    if (this.retryTimer !== null) { this.deps.clearTimer(this.retryTimer); this.retryTimer = null; }
  }

  /** Let go of the socket now; closed() ignores its onclose. */
  private drop(): void {
    const ws = this.socket;
    this.socket = null;
    if (ws) { try { ws.close(1000); } catch { /* already closed */ } }
    this.reset();
  }

  private reset(): void {
    this.ghosts.clear();
    this.peers = 0;
    this.selfId = null;
    this.openedAt = 0;
    this.sendState = newSendState();
  }

  private receive(data: unknown): void {
    const m = parseServerMessage(data);
    if (!m) return;
    switch (m.t) {
      case "hello": this.selfId = m.id; this.peers = m.peers; break;
      case "peers": this.peers = m.n; if (m.n === 0) this.ghosts.clear(); break;
      case "sync": this.sendState.syncPending = true; break;
      case "snap": this.ghosts.push(m.ships.filter((s) => s.id !== this.selfId), this.deps.now()); break;
      case "full": this.full = true; this.cancelRetry(); this.drop(); break;
    }
  }
}
```

```tsx
function makeSlot(shipScene: THREE.Object3D, flameGeometry: THREE.BufferGeometry, i: number): Slot {
  const stock = new THREE.Color(PLUME_COLORS.stock.hex);
  // RingCourse's race-ghost material, parameter for parameter, so the two
  // share one already-compiled program. Colour and opacity are uniforms.
  const hull = new THREE.MeshBasicMaterial({

  });
  const model = shipScene.clone(true);
  model.traverse((o) => { if ((o as THREE.Mesh).isMesh) (o as THREE.Mesh).material = hull; });
  model.scale.setScalar(0.35);
  model.rotation.set(0, Math.PI, 0);
  model.position.set(0, -0.05, 0);
  const flame = makePlumeMaterial(i * 1.7, stock);
  flame.uniforms.uPower.value = GHOST_PLUME_POWER;
  const plume = new THREE.Mesh(flameGeometry, flame);
  plume.position.set(0, NOZZLE_Y, NOZZLE_Z - GHOST_PLUME_LEN / 2);

  plume.scale.set(1, GHOST_PLUME_LEN, 1);
  plume.frustumCulled = false;
  const group = new THREE.Group();
  group.name = `LiveGhost_${i}`;
  group.visible = false;
  group.add(model, plume);
  return { group, hull, flame, plume: "stock", scanId: null };

function releaseScan(slot: Slot) {
  if (!slot.scanId) return;
  removeScannable(slot.scanId);
  ghostRegistry.delete(slot.scanId);
  slot.scanId = null;
}

 * other pilots flying now, as up to 8 pooled ghost ships. Drives the
 * connection per frame. Mounted only when the live sky URL is configured; the
 * canvas (and so this) unmounts on the classic résumé, which closes the socket.

  const flameGeometry = useMemo(() => makePlumeGeometry(0.07), []);
  const slots = useMemo(
    () => Array.from({ length: MAX_GHOSTS }, (_, i) => makeSlot(shipScene, flameGeometry, i)),
    [shipScene, flameGeometry],
  );

    url: liveSkyUrl(),
    createSocket: (u) => new WebSocket(u) as unknown as SocketLike,
    now: () => performance.now(),
    setTimer: (fn, ms) => window.setTimeout(fn, ms),
    clearTimer: (h) => window.clearTimeout(h as number),
    random: Math.random,
  }), []);
  const noticeQueued = useRef(false);
  const wanted = useRef(false);

  useEffect(() => () => {
    conn.dispose();
    for (const s of slots) { releaseScan(s); s.hull.dispose(); s.flame.dispose(); }
    flameGeometry.dispose();
  }, [conn, slots, flameGeometry]);

  useEffect(() => {
    if (!import.meta.env.DEV) return;
    fitzDebug.liveSky = conn;
    return () => { fitzDebug.liveSky = null; };
  }, [conn]);

  useEffect(() => {
    const onVisibility = () => conn.setVisible(!document.hidden);
    onVisibility();
    document.addEventListener("visibilitychange", onVisibility);
    return () => document.removeEventListener("visibilitychange", onVisibility);
  }, [conn]);

  // Consent (spec §5): the ship becomes shareable once the notice has actually
  // reached the radio, not merely been queued.
  useEffect(() => useSpaceStore.subscribe((s) => s.broadcast, (b) => {
    if (b?.text === LIVE_SKY_NOTICE && !useSpaceStore.getState().liveSkySeen) useSpaceStore.getState().setLiveSkySeen(true);
  }), []);

  useFrame((state) => {
    const s = useSpaceStore.getState();
    if (s.liveSky && flight.hasFlown && !s.liveSkySeen && !noticeQueued.current) {
      noticeQueued.current = true;
      s.announceLogbook(LIVE_SKY_NOTICE);
    }
    const want = s.liveSky && flight.hasFlown && (s.liveSkySeen || noticeQueued.current);
    if (want !== wanted.current) { wanted.current = want; conn.setWanted(want); }

    if (s.liveSkySeen && conn.peers > 0) {
      conn.tick({ p: [flight.x, flight.y, flight.z], q: shipQuat(flight.heading, flight.pitch), plume: s.plumeColor });
    }

    const poses = conn.ghosts.size
      ? nearestGhosts(flight, conn.ghosts.sample(performance.now(), s.reducedMotion ? 0 : FADE_IN_MS), MAX_GHOSTS)
      : NONE;
    const t = state.clock.getElapsedTime();
    // Pass 1: release every slot whose ghost changed or left, so pass 2 can
    // re-register an id that moved to another slot this frame.
    for (let i = 0; i < slots.length; i++) {
      const g = poses[i];
      if (!g || slots[i].scanId !== ghostScanId(g.id)) releaseScan(slots[i]);
    }
    for (let i = 0; i < slots.length; i++) {
      const slot = slots[i];
      const g = poses[i];
      if (!g) {
        if (slot.group.visible) slot.group.visible = false;
        continue;
      }
      slot.group.visible = true;
      // The nearest wrapped copy of the ghost, as seen from this ship.
      slot.group.position.set(
        flight.x + wrapDelta(flight.x, g.p[0], B),
        flight.y + wrapDelta(flight.y, g.p[1], B),
        flight.z + wrapDelta(flight.z, g.p[2], B),
      );
      slot.group.quaternion.set(g.q[0], g.q[1], g.q[2], g.q[3]);
      if (slot.plume !== g.plume) {
        slot.plume = g.plume;
        const hex = (PLUME_COLORS[g.plume] ?? PLUME_COLORS.stock).hex;
        slot.hull.color.set(hex).multiplyScalar(GHOST_WASH);
        (slot.flame.uniforms.uColor.value as THREE.Color).set(hex);
      }
      slot.hull.opacity = g.alpha;
      slot.flame.uniforms.uPower.value = GHOST_PLUME_POWER * g.alpha;
      slot.flame.uniforms.uTime.value = t;
      slot.scanId = ghostScanId(g.id);
      ghostRegistry.set(slot.scanId, g.cc);
      setScannable(slot.scanId, g.p[0], g.p[1], g.p[2], GHOST_LABEL);
    }
  });

  return (
    <group name="LiveSky">
      {slots.map((s) => <primitive key={s.group.name} object={s.group} />)}
    </group>
  );
}
```

```js
  SCENE_READY_TIMEOUT_MS,

// Runs in the page before any script (evaluateOnNewDocument). Fakes only
// fake:// sockets; everything else (Vite's HMR) gets the real WebSocket.
function installFakeSky() {
  const sky = { created: 0, sent: [], sockets: [] };
  window.__fakeSky = sky;
  class FakeSocket {
    constructor(url) {
      this.url = url;
      this.readyState = 0;
      this.onopen = null; this.onmessage = null; this.onclose = null; this.onerror = null;
      sky.created++;
      sky.sockets.push(this);
      setTimeout(() => { if (this.readyState !== 0) return; this.readyState = 1; this.onopen?.(); }, 20);
    }
    send(d) { sky.sent.push(JSON.parse(d)); }
    close() {
      if (this.readyState === 3) return;
      this.readyState = 3;
      setTimeout(() => this.onclose?.(), 0);
    }
  }
  sky.serve = (msg) => { for (const s of sky.sockets) if (s.readyState === 1) s.onmessage?.({ data: JSON.stringify(msg) }); };
  sky.open = () => sky.sockets.filter((s) => s.readyState === 1).length;
  window.WebSocket = new Proxy(window.WebSocket, {
    construct(target, args) {
      return String(args[0]).startsWith("fake://") ? new FakeSocket(args[0]) : Reflect.construct(target, args);
    },
  });
}

      localStorage.removeItem("fitz-live-seen");
      localStorage.removeItem("fitz-live-sky");

    checks.check("nothing connects before the ship has flown", created0 === 0, `created=${created0}`);

    const seen = await pollUntil(async () => (await readStore(page)).liveSkySeen === true, { timeoutMs: 5000 });
    checks.check("the notice is remembered once shown", seen.ok);

    await inPage(page, () => window.__fakeSky.serve({ t: "hello", id: "me1", peers: 0 }));
    await hold(page, ["KeyW"], 800);
    const aloneSent = await inPage(page, () => window.__fakeSky.sent.length);
    checks.check("alone, the client sends nothing", aloneSent === 0, `sent=${aloneSent}`);
    await settle(page, 3000); // coast to a stop

    const programsBefore = await inPage(page, () => window.__fitz.gl.info.programs.length);
    const ship = await inPage(page, () => ({ x: window.__fitz.flight.x, y: window.__fitz.flight.y, z: window.__fitz.flight.z }));
    const snap = (dx) => ({ t: "snap", ships: [
      { id: "g1", p: [ship.x + 6 + dx, ship.y, ship.z], q: [0, 0, 0, 1], plume: "ring", cc: "ID" },
      { id: "g2", p: [ship.x - 16, ship.y, ship.z + dx], q: [0, 0, 0, 1], plume: "stock", cc: null },
    ] });
    await inPage(page, (s) => { window.__fakeSky.serve({ t: "peers", n: 2 }); window.__fakeSky.serve(s); }, snap(0));
    const visible = await pollUntil(async () => (await sceneQuery(page, "LiveGhost_0")).visible, { timeoutMs: 5000 });
    checks.check("ghosts appear for pilots in the room", visible.ok);
    const sent = await inPage(page, () => window.__fakeSky.sent);
    checks.check("with company, the client shares its pose once", sent.length >= 1 && sent[0].t === "me" && sent[0].plume === "stock",
      JSON.stringify(sent[0]));

    // Smoothness: record the nearest ghost's offset from the ship every frame
    // while a moved snapshot arrives; it should glide, not teleport.
    const xs = await inPage(page, async (next) => {
      const g = () => window.__fitz.scene.getObjectByName("LiveGhost_0");
      const out = [];
      const t0 = performance.now();
      setTimeout(() => window.__fakeSky.serve(next), 100);
      await new Promise((done) => {
        const step = () => {
          out.push(g().position.x - window.__fitz.flight.x);
          if (performance.now() - t0 < 1200) requestAnimationFrame(step); else done();
        };
        requestAnimationFrame(step);
      });
      return out;
    }, snap(1.2));
    const x0 = xs[0], x1 = xs.at(-1);
    const between = xs.some((v) => v > x0 + 0.15 && v < x1 - 0.15);
    checks.check("a ghost glides between snapshots", x1 - x0 > 1 && between,
      `from=${x0?.toFixed(2)} to=${x1?.toFixed(2)} frames=${xs.length}`);

    await settle(page, 1000);
    const programsAfter = await inPage(page, () => window.__fitz.gl.info.programs.length);
    checks.check("ghosts add no shader program", programsAfter === programsBefore,
      `before=${programsBefore} after=${programsAfter}`);

    const target = await pollUntil(async () => (await readStore(page)).scanTarget !== null, { timeoutMs: 3000 });
    checks.check("a ghost is a scan target", target.ok);
    await hold(page, ["KeyE"], 2600); // scan takes 1.6s
    const after = await readStore(page);
    checks.check("scanning a ghost names its pilot's country", after.broadcast?.text === "PILOT FROM ID · LIVE",
      `broadcast=${after.broadcast?.text}`);
    checks.check("a ghost scan earns no badge", !after.badges.some((b) => b.id === "comet"));

    await page.evaluate(() => window.__fitz.store.getState().setLogbookOpen(true));
    await page.click('[data-testid="livesky-toggle"]');
    const off = await page.$eval('[data-testid="livesky-toggle"]', (el) => el.getAttribute("aria-checked"));
    checks.check("the logbook switch turns live sky off", off === "false", `aria-checked=${off}`);
    const gone = await pollUntil(async () => !(await sceneQuery(page, "LiveGhost_0")).visible, { timeoutMs: 3000 });
    checks.check("turning it off hides the ghosts", gone.ok);
    const open = await inPage(page, () => window.__fakeSky.open());
    checks.check("turning it off closes the socket", open === 0, `open=${open}`);
    await settle(page, 800);
    const s2 = await readStore(page);
    checks.check("turning it off removes the ghost scan target", s2.scanTarget === null, `scanTarget=${s2.scanTarget}`);

    await page.evaluate(() => {
      localStorage.removeItem("fitz-live-sky-dev");
      localStorage.removeItem("fitz-live-sky");
      localStorage.removeItem("fitz-live-seen");
    });
  });
}
```
