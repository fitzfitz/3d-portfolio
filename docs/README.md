# Docs map

## Current, kept up to date

- `README.md` (repo root): what the project is, how to run, test and deploy it.
- `docs/UNIVERSE-RULES.md`: the rules every world, body and scale in the universe must obey.
- `docs/PERF-BUDGETS.md`: performance and memory budgets, measured baselines and how to compare against them.
- `docs/FOLLOW-UPS.md`: known leftovers and ideas that were deferred from shipped work.
- `docs/QA-CHECKLIST.md`: the manual checks to run before a release.
- `beacon-api/README.md`: the Cloudflare Worker behind beacons, live sky and dossier content.
- `assets-src/MANIFEST.md`: provenance and licences of the source art (`assets-src/` is a separate private repo).

## Archive

`docs/archive/` is the historical record of decisions (`specs/`) and build plans (`plans/`), named by date. It may be stale: the code and the current docs win.

## New work

New feature specs and plans go in `docs/superpowers/specs/` and `docs/superpowers/plans/`. Move them to the archive once shipped.
